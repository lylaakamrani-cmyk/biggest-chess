# ♟️ Chess Master Pro

یک بازی شطرنج کامل و حرفه‌ای با پایتون و کتابخانه‌های python-chess و kivy

## معرفی

Chess Master Pro یک بازی شطرنج کامل و حرفه‌ای است که با استفاده از پایتون و کتابخانه‌های python-chess و kivy ساخته شده است. این بازی شامل قابلیت‌های پیشرفته‌ای مانند بازی آنلاین، بازی با هوش مصنوعی، سیستم رتبه‌بندی ELO، فروشگاه، تنظیمات، تورنمنت و تحلیل بازی می‌باشد.

## ویژگی‌ها

- بازی آنلاین و آفلاین (محلی)
- پشتیبانی از استانداردهای کامل شطرنج (قوانین FIDE)
- موتور قدرتمند شطرنج (Stockfish)
- تحلیل کامل بازی بعد از اتمام
- پروفایل کاربری با آمار و رکوردها
- فروشگاه برای خرید تم‌ها و مهره‌ها
- تنظیمات شامل صدا، انیمیشن، تم، و زمان
- بازی با هوش مصنوعی در سطوح مختلف
- سیستم رتبه‌بندی ELO
- لیست دوستان و امکان دعوت به بازی
- چت داخل بازی
- سیستم تورنمنت و مسابقات آنلاین
- همگام‌سازی اطلاعات بین دستگاه‌ها
- پوسته‌های متنوع برای صفحه و مهره‌ها
- اعلان‌های هوشمند
